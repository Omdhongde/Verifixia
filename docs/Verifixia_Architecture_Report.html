2. Multi-Class Image Detector (Primary Tier 1)
The primary deep learning model is a custom 3-class classifier designed to separate authentic media from manipulations (AI synthesis vs. classical splicing).
Model Filemodels/multiclass_detector.pth
ArchitectureCustom ResNet-style CNN with Squeeze-Excitation (SE) Attention Blocks
Target Classes3 classes: 0 = Real, 1 = Deepfake, 2 = AI-Generated

Input Dimensions3 channels × 299 × 299 pixels

6. Non-GPU Fallback Classifiers (Tiers 2 & 3)

To guarantee high system availability and zero downtime on low-resource environments (such as basic CPU nodes), Verifixia integrates non-deep-learning classifiers.

Tier 2 Fallback: scikit-learn SVM

Classifier TypeSupport Vector Machine (SVM) with RBF Kernel
Feature SetHistogram of Oriented Gradients (HOG) + RGB/YCbCr color histograms + FFT spectrum
Input Size128 × 128 pixels (downscaled for fast feature extraction)
Saved Package Filemodels/deepfake_sklearn.pkl

Tier 3 Fallback: Heuristic Analysis

If both PyTorch and scikit-learn modules fail, the system runs raw pixel statistics using standard Pillow libraries, evaluating absolute brightness offsets and standard deviation contrast measurements.

Cartoon & Synthetic Art Detector (Pre-processing)

A dedicated heuristic filter checks color variety and channel uniformity before heavy processing. Since realistic deepfake models perform poorly on illustrated media, drawings are immediately classified as Synthetic/Fake with 90% confidence, saving CPU/GPU resources.
